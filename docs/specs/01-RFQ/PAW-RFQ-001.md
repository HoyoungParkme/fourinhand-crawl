# RFQ — 요구·인터뷰

## 1. 배경과 동기

포인핸드(https://pawinhand.kr/)는 전국 동물보호센터의 유기동물 공고를 모아 보여주는 서비스다. 사이트의 검색 필터는 지역·축종·품종·상태·성별·중성화·기간만 있고 **몸무게로는 거를 수 없다.** 고객은 보호 중인 고양이 가운데 몸무게가 8kg 이상인 아이만 한눈에 보고 싶어 한다.

사전 조사로 확인한 사실(판단이 아니라 관찰):

| 항목 | 확인한 것 |
|---|---|
| 사이트 구조 | Vue 단일 페이지 앱. 목록 데이터는 `https://pawinhand.net/bridge/animals/condition`에서 JSON으로 받는다 |
| 조회 조건 | `species=고양이`, `state=보호중`, `start_date`·`end_date`(YYYYMMDD, 공고 등록일 기준), `offset`·`limit`. 조건 값의 공백은 `+`로 인코딩해야 한다 — `%20`이면 빈 배열이 온다 |
| 몸무게 필드 | `weight` 문자열. 예: `8(Kg)`, `9.00(Kg)`. 형식이 들쭉날쭉하다 — `0,39(Kg)`(쉼표 소수점), `0..8(Kg)`, `800(Kg)`·`630(Kg)`(단위 오기로 보임), 빈 값, `https://ww(Kg)` 같은 깨진 값 |
| 목록 한 건에 든 정보 | 사진(최대 3장), 공고번호, 공고 기간, 성별, 품종, 색, 나이, 중성화, 특징, 상태, 발견 장소, 보호소 이름·주소·전화, 관할 기관, 몸무게 |
| 상세 페이지 주소 | `https://pawinhand.kr/shelter/animal/detail/{공고번호}` — 공고번호(`notify_number`, 예: `전북-김제-2026-00294`)로 열린다. 브라우저로 열어 해당 동물 정보가 뜨는 것을 확인 |
| 규모(2026-09-30 기준) | 보호중 고양이: 최근 3개월 등록 2,122건 · 최근 1년 2,748건 · 2020년 이후 4,225건 |
| robots.txt | `Allow: /` |

## 3. 요구 사항

#### Q1 보호중 고양이 중 8kg 이상만 목록으로

포인핸드에 등록된 고양이 중 **보호중**인 아이들 가운데 **몸무게가 8kg 이상**인 아이만 검색해서 리스트업해 주는 서비스를 만든다.

#### Q2 싱크독 명세 기반 개발

싱크독 명세서를 근거로 만든다.

#### Q3 exe 설치 파일로 배포

exe 설치 파일로 다른 사람들에게 주면, 받은 사람이 바로 설치해서 쓸 수 있어야 한다. 고객 표현으로 「설치하고 쓰는 프로그램」이다.

#### Q4 프로그램 안에서 목록과 내용 보기

프로그램이 포인핸드에서 목록을 받아 와서, 그 안에 있는 내용을 프로그램 화면에 보여준다.

#### Q5 링크를 누르면 해당 페이지로 이동

목록에서 링크를 누르면 그 아이의 해당 페이지로 간다.

#### Q6 조회 기간은 앱에서 필터로

조회 기간은 앱 화면에서 필터로 거른다.

#### Q7 이상한 몸무게 값은 그램으로

`800(Kg)`처럼 kg로 보기 어려운 값은 그램으로 해석한다.

#### Q8 Tauri로 만들고 Windows에서 개발

프로그램은 Tauri(Rust + 웹 화면)로 만든다. 개발은 WSL이 아니라 Windows에서 직접 한다. 개발 PC에도 빌드 도구를 설치하고, 배포용 설치 파일은 GitHub Actions로도 만든다. 코드 서명은 하지 않고 설치 안내문으로 대신한다.

## 4. 사용자와 환경

| 누구 | 환경 |
|---|---|
| 고객 본인 | Windows 11 PC. 개발도 이 PC의 Windows에서 한다 |
| 설치 파일을 받는 다른 사람들 | Windows PC로 추정. 개발 도구가 없다고 가정해야 「바로 설치」가 성립한다 |
