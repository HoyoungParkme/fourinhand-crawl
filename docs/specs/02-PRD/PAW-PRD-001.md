# PRD — 제품 요구

## 1. 목표

#### G1 보호 중인 8kg 이상 고양이를 한 화면에서 찾는다

포인핸드는 몸무게로 거를 수 없어서, 큰 고양이를 찾으려면 수천 건을 하나씩 열어 봐야 한다. 프로그램이 대신 모아서 걸러 준다. 근거: [[PAW-RFQ-001#Q1]] · [[PAW-RFQ-001#Q4]]

#### G2 개발 도구 없는 사람도 설치 파일 하나로 쓴다

받은 사람이 파이썬·Node 같은 것을 몰라도 설치해서 바로 쓸 수 있어야 나눠 줄 수 있다. 근거: [[PAW-RFQ-001#Q3]] · [[PAW-RFQ-001#Q8]]

#### G3 찾은 아이의 원래 공고로 바로 간다

입양 문의·신청은 포인핸드와 보호소에서 한다. 프로그램은 거기까지 한 번에 데려다준다. 근거: [[PAW-RFQ-001#Q5]]

## 2. 비목표

| 비목표 | 이유 |

| 자체 서버·DB | 프로그램이 포인핸드에 직접 묻는다. 운영할 서버를 두지 않는다 |

| 자동 업데이트 | 1차 버전은 새 설치 파일로 다시 설치 |
| 코드 서명 | 설치 안내문으로 대신한다. 근거: [[PAW-RFQ-001#Q8]] |

| 몸무게 값 바로잡기 | 원본은 보호소가 입력한 값이다. 프로그램은 정해진 규칙으로 해석만 하고 원래 값도 같이 보여준다 |

## 3. 요구사항

### 3.1 기능

#### R1 보호중 고양이 전부 받아오기

근거: [[PAW-RFQ-001#Q1]] · [[PAW-RFQ-001#Q6]]

포인핸드 목록 API에서 `species=고양이`, `state=보호중`, 등록일 2020-01-01부터 오늘까지를 받는다. 한 번에 1000건씩, 받은 건수가 1000보다 적을 때까지 다음 쪽을 이어 받는다. 사이트가 「공고중」으로 보여주는 아이(공고 기간이 남은 아이)도 API에서는 `보호중`으로 오므로 함께 들어온다.

- [ ] 조건 값의 공백을 `+`로 인코딩해 보낸다 (`%20`이면 빈 배열이 온다)
- [ ] 마지막 쪽까지 빠짐없이 받는다 — 2026-09-30 기준 4,225건, 5번 요청
- [ ] 공고번호(`notify_number`)가 같은 건이 두 번 오면 하나만 남긴다

#### R2 몸무게 해석

근거: [[PAW-RFQ-001#Q7]]

`weight` 문자열을 kg 숫자로 바꾼다. 순서대로 적용한다.

1. `(Kg)`과 공백을 지운다
2. 쉼표를 점으로 바꾸고, 이어진 점은 하나로 줄인다 (`0..8` → `0.8`, `0.,53` → `0.53`)
3. 점으로 시작하면 앞에 0을 붙인다 (`.9` → `0.9`)
4. **0으로 시작하고 뒤에 숫자만 있으면(점 없음) 0 뒤에 점이 빠진 것으로 본다** (`017` → `0.17`, `0312` → `0.312`). 고객 결정 — `017`은 0.17kg(170g)이다
5. 숫자로 바뀌지 않으면 「몸무게 없음」이다 (빈 값, `https://ww`)
6. **30보다 크면 그램으로 보고 1000으로 나눈다** (`800` → 0.8, `630` → 0.63). 고양이 몸무게로 30kg은 나올 수 없다는 것이 경계의 근거다

그 밖의 값은 규칙으로 바꾸지 않는다. `15(Kg)`처럼 고양이로는 드문 값도 15kg으로 해석하고, 원래 값을 함께 보여준다(R8).

- [ ] `9.00(Kg)` → 9.0 · `0,39(Kg)` → 0.39 · `0..8(Kg)` → 0.8 · `.9(Kg)` → 0.9
- [ ] `017(Kg)` → 0.17 · `0312(Kg)` → 0.312 · `0(Kg)` → 0
- [ ] `800(Kg)` → 0.8 · `850(Kg)` → 0.85
- [ ] `15(Kg)` → 15
- [ ] 빈 값 · `https://ww(Kg)` → 몸무게 없음. 몸무게 없음은 어떤 기준에도 걸리지 않는다
- [ ] 해석한 값과 원래 문자열을 둘 다 보관한다

#### R3 몸무게 기준 필터

근거: [[PAW-RFQ-001#Q1]] · RFQ 6절 승인(추천안)

해석한 몸무게가 기준 **이상**인 아이만 보여준다. 기준은 기본 8kg이고 화면에서 숫자로 바꿀 수 있다.

- [ ] 처음 켜면 기준은 8kg이다
- [ ] 기준을 0.1kg 단위로 바꿀 수 있고, 바꾸면 다시 받아오지 않고 바로 목록이 바뀐다
- [ ] 8.0kg은 기준 8kg에 포함된다

#### R4 기간 필터

근거: [[PAW-RFQ-001#Q6]]

공고 등록일(`registration_date`)로 거른다. 받아올 때는 넓게 받고(R1), 기간은 화면에서 고른다. 몇 년 된 공고가 아직 「보호중」으로 남아 있는 경우도 이 필터로 거른다 — 따로 표시하지 않는다(고객 결정).

- [ ] 선택지: 전체 · 최근 1년 · 최근 6개월 · 최근 3개월
- [ ] 기본값은 전체다 — 8kg 이상은 전체 기간이어도 수십 건 안쪽이라(2026-09-30 기준 15건) 가려서 놓치는 것보다 다 보이는 편이 낫다
- [ ] 기간을 바꾸면 다시 받아오지 않고 바로 목록이 바뀐다

#### R5 지역(시·도) 필터

근거: RFQ 6절 승인(추천안)

`city` 값으로 거른다. 선택지는 받아온 데이터에 실제로 있는 시·도로 만든다 — 행정구역 이름이 바뀌기도 해서(`전남광주통합특별시` 같은 값이 실제로 온다) 목록을 코드에 박아 두지 않는다.

- [ ] 기본값은 전국이다
- [ ] 시·도가 빈 값인 아이는 「지역 미상」으로 묶는다
- [ ] 각 선택지 옆에 현재 기준에 걸리는 건수를 보여준다

#### R6 정렬

근거: RFQ 6절 승인(추천안)

- [ ] 기본은 몸무게 무거운 순이다
- [ ] 등록일 최신순으로 바꿀 수 있다

#### R7 목록 카드

근거: [[PAW-RFQ-001#Q4]] · RFQ 6절 승인(추천안)

한 아이를 카드 하나로 보여준다.

- [ ] 대표 사진, 몸무게(해석값), 나이, 성별, 보호소 이름, 공고 기간을 보여준다
- [ ] 상태 배지: 공고 종료일(`notify_edt`)이 오늘 이후면 「공고중」, 지났으면 「보호중」. 포인핸드 사이트와 같은 규칙이다
- [ ] 사진을 못 불러오면 빈 자리 그림을 보여주고 카드는 그대로 둔다
- [ ] 목록 위에 「N마리」로 현재 걸린 수를 보여준다

#### R8 상세 보기

근거: [[PAW-RFQ-001#Q4]] · RFQ 6절 승인(추천안)

카드를 누르면 그 아이의 나머지 정보를 보여준다.

- [ ] 사진 최대 3장, 품종, 색, 중성화 여부, 특징, 발견 장소, 보호소 주소·전화, 관할 기관, 공고번호
- [ ] 몸무게는 해석값과 원래 문자열을 함께 보여준다 (예: `0.8kg (원래 값: 800(Kg))`)
- [ ] 목록으로 돌아가면 보던 위치와 필터가 그대로다

#### R9 원래 페이지로 가는 링크

근거: [[PAW-RFQ-001#Q5]] · RFQ 6절 승인(추천안)

- [ ] 「포인핸드에서 보기」를 누르면 `https://pawinhand.kr/shelter/animal/detail/{공고번호}`가 **기본 브라우저**로 열린다
- [ ] 원문 링크(`detail_url`, 국가동물보호정보시스템)가 있으면 작은 링크로 함께 둔다
- [ ] 목록 카드에서도 상세를 거치지 않고 바로 포인핸드로 갈 수 있다

#### R10 불러오기와 새로고침

근거: RFQ 6절 승인(추천안)

- [ ] 프로그램을 켜면 바로 받아오기 시작한다
- [ ] 받는 동안 진행 상태(몇 건 받았는지)를 보여준다
- [ ] 「새로고침」 버튼으로 다시 받는다. 받는 중에는 버튼이 눌리지 않는다
- [ ] 실패하면(인터넷 끊김, 포인핸드 응답 없음) 이유와 「다시 시도」 버튼을 보여준다. 프로그램은 꺼지지 않는다
- [ ] 마지막으로 받은 시각을 보여준다

#### R11 설치 파일

근거: [[PAW-RFQ-001#Q3]] · [[PAW-RFQ-001#Q8]]

- [ ] `setup.exe` 하나를 실행하면 설치된다. 관리자 권한 없이 현재 사용자에게 설치할 수 있다
- [ ] 시작 메뉴에 바로가기가 생기고, Windows 「앱 제거」로 지울 수 있다
- [ ] WebView2가 없는 PC에서는 설치 중에 받아서 깐다

#### R12 배포와 설치 안내

근거: [[PAW-RFQ-001#Q8]]

- [ ] 버전 태그를 올리면 GitHub Actions가 `setup.exe`를 만들어 GitHub Releases에 올린다
- [ ] README에 설치 방법을 적는다 — 코드 서명이 없어 뜨는 「Windows의 PC 보호」 창에서 「추가 정보 → 실행」을 누르는 법을 그림과 함께

### 3.2 비기능

#### N1 받아오기 속도

- [ ] 전체(약 4,000~5,000건) 받아오기가 보통 인터넷에서 10초 안에 끝난다. 2026-09-30 실측 3.3초

#### N2 포인핸드에 부담 주지 않기

- [ ] 요청은 한 번에 하나씩, 앞 요청이 끝난 뒤 보낸다
- [ ] 요청 사이 0.3초 이상 쉰다
- [ ] 자동 반복 조회를 하지 않는다. 받는 때는 켤 때와 새로고침을 누를 때뿐이다

#### N3 설치 파일 크기

- [ ] `setup.exe`가 20MB 이하다

#### N4 지원 환경

- [ ] Windows 10·11 64비트

#### N5 개인정보

- [ ] 사용자 정보를 모으거나 밖으로 보내지 않는다. 나가는 요청은 포인핸드 API와 사진 주소(`animal.go.kr`)뿐이다

## 4. 성공지표

| 지표 | 목표 | 재는 법 |
|---|---|---|
| 8kg 이상 누락 | 0건 | 받은 원본 전체에 R2 규칙을 따로 적용한 결과와 화면 건수 대조 |
| 설치부터 첫 목록까지 | 3분 이내 | 개발 도구 없는 PC에서 `setup.exe` 받고 → 설치 → 켜서 목록이 뜰 때까지 |
| 링크 정확도 | 100% | 목록의 모든 아이에 대해 포인핸드 링크가 그 아이 페이지를 여는지 확인 |
| 받아오기 시간 | 10초 이내 | N1 |

## 6. 미결사항

- [x] **앞자리 0 값** — `017(Kg)`은 0.17kg(170g)으로 본다. 「0으로 시작하고 점이 없으면 0 뒤에 점이 빠진 것」 규칙을 [[#R2]] 4단계로 넣었다
- [x] **비현실적으로 큰 값** — `15(Kg)`처럼 드문 값은 규칙으로 바꾸지 않고 원래 값을 함께 보여준다([[#R8]]). 별도 표시 없음
- [x] **오래된 공고** — 따로 표시하지 않고 기간 필터로 거른다. 기본값 「전체」 유지([[#R4]])
