# 사용자 시나리오

## 0. 범위와 전제

- 프로그램은 Windows PC에 설치해서 쓰는 데스크톱 앱이다. 로그인·회원가입이 없다
- 데이터는 켤 때와 새로고침을 누를 때 포인핸드에서 받아온다. 프로그램에 저장해 두지 않는다
- 입양 문의·신청은 프로그램 밖(포인핸드·보호소)에서 한다. 시나리오는 포인핸드 페이지가 브라우저에 열리는 데서 끝난다
- 숫자 예시는 2026-09-30 실제 데이터 기준이다(보호중 고양이 4,225건, 8kg 이상 15건)

## 1. 페르소나

#### P1 큰 고양이를 입양하고 싶은 사람

- **역할**: 설치 파일 링크를 받아 프로그램을 쓰는 사람. 컴퓨터는 웹서핑·카톡 정도로 쓰고 개발 도구는 모른다
- **겪는 문제**: 포인핸드에서 고양이 공고가 수천 건인데 몸무게로 거를 수 없다. 큰 아이를 찾으려면 하나씩 열어 몸무게를 봐야 한다
- **원하는 것**: 켜면 8kg 넘는 아이만 바로 보이고, 마음에 드는 아이의 포인핸드 페이지로 한 번에 가는 것

#### P2 배포자

- **역할**: 프로그램을 만들고 새 버전을 나눠 주는 사람(고객 본인). GitHub 저장소를 관리한다
- **겪는 문제**: 받는 사람마다 PC 환경이 달라서 「설치가 안 돼요」 같은 문의를 일일이 받기 어렵다
- **원하는 것**: 태그 하나 올리면 설치 파일이 만들어지고, 링크 하나만 알려주면 받는 사람이 알아서 설치하는 것

## 2. 시나리오

#### S1 처음 설치하고 첫 목록 보기

**주체**: P1
**상황**: 지인에게 GitHub Releases 링크를 받았다. PC에 이 프로그램이 없다.

1. 링크를 열어 `setup.exe`를 내려받는다 (20MB 이하)
2. `setup.exe`를 실행하면 「Windows의 PC 보호」 창이 뜬다. 링크와 함께 받은 안내(README)대로 「추가 정보 → 실행」을 누른다
3. 설치 마법사를 따라 설치한다. 관리자 비밀번호를 묻지 않는다
4. 시작 메뉴에서 프로그램을 연다
5. 프로그램이 바로 포인핸드에서 보호중 고양이를 받아오기 시작한다. 화면에 「1,000 / 받는 중…」처럼 진행 상태가 보인다
6. 몇 초 뒤 받아오기가 끝나고, 몸무게 8kg 이상인 아이가 무거운 순으로 카드 목록에 뜬다. 목록 위에 「15마리」와 마지막으로 받은 시각이 보인다

**변형 — WebView2가 없는 PC**: 3에서 설치 프로그램이 WebView2를 내려받아 먼저 깔고 이어서 설치한다. 사용자가 따로 할 일은 없다.

**변형 — 인터넷이 끊겨 있음**: 5에서 받아오기가 실패한다. 화면에 「포인핸드에 연결하지 못했어요」와 이유, 「다시 시도」 버튼이 뜬다. 프로그램은 꺼지지 않는다. 인터넷을 연결하고 「다시 시도」를 누르면 5부터 다시 한다.

**변형 — 경고 창에서 멈춤**: 2에서 「실행 안 함」만 보이고 「추가 정보」를 못 찾는다. 안내문의 그림을 보고 「추가 정보」 글자를 누르면 「실행」 버튼이 나타난다.

**성공 조건**: 링크를 받은 뒤 3분 안에 8kg 이상 고양이 목록을 본다. 설치 과정에서 개발 도구나 회원가입을 요구받지 않는다.
**연관 요구사항**: [[PAW-PRD-001#R1]] · [[PAW-PRD-001#R2]] · [[PAW-PRD-001#R3]] · [[PAW-PRD-001#R10]] · [[PAW-PRD-001#R11]] · [[PAW-PRD-001#R12]] · [[PAW-PRD-001#N1]] · [[PAW-PRD-001#N3]] · [[PAW-PRD-001#N4]] · [[PAW-PRD-001#N5]]

#### S2 조건을 바꿔 가까운 아이 찾기

**주체**: P1
**상황**: 목록을 보니 먼 지역 아이가 많다. 사는 곳 근처에서, 최근에 올라온 공고 위주로 보고 싶다.

1. 지역 선택에서 「경기도」를 고른다. 선택지마다 옆에 현재 걸리는 마릿수가 보인다
2. 목록이 경기도 아이만으로 바로 바뀐다. 다시 받아오지 않는다
3. 기간을 「최근 3개월」로 바꾼다. 몇 년 된 공고가 빠진다
4. 결과가 적어서 몸무게 기준을 8에서 7로 내려 본다. 7kg 이상 아이까지 목록에 들어온다
5. 정렬을 「등록일 최신순」으로 바꿔 새로 올라온 아이부터 본다

**변형 — 조건에 맞는 아이가 없음**: 2~4 어디서든 목록이 0마리가 되면 빈 화면 대신 「조건에 맞는 아이가 없어요」와 함께 지금 조건(지역·기간·기준)을 보여준다. 조건을 되돌리면 목록이 다시 채워진다. 요구: [[PAW-PRD-001#R7]]

**변형 — 지역 미상**: 보호소 시·도가 비어 있는 아이는 지역 선택의 「지역 미상」에 모여 있다.

**성공 조건**: 필터를 바꿀 때마다 기다림 없이 목록이 바뀌고, 지금 몇 마리가 걸렸는지 항상 보인다.
**연관 요구사항**: [[PAW-PRD-001#R3]] · [[PAW-PRD-001#R4]] · [[PAW-PRD-001#R5]] · [[PAW-PRD-001#R6]] · [[PAW-PRD-001#R7]]

#### S3 한 아이를 자세히 보고 포인핸드로 가기

**주체**: P1
**상황**: 목록에서 마음에 드는 아이를 발견했다.

1. 카드를 누르면 상세 보기가 열린다
2. 사진 최대 3장, 품종·색·중성화·특징, 발견 장소, 보호소 이름·주소·전화, 관할 기관, 공고번호를 본다
3. 몸무게는 「9kg (원래 값: 9.00(Kg))」처럼 해석값과 보호소가 적은 원래 값이 함께 보인다
4. 카드 배지로 이 아이가 「공고중」인지 「보호중」인지 확인한다
5. 「포인핸드에서 보기」를 누르면 기본 브라우저에 그 아이의 포인핸드 페이지가 열린다
6. 포인핸드에서 입양 문의·신청을 이어간다
7. 프로그램으로 돌아와 목록으로 가면 보던 위치와 필터가 그대로다

**변형 — 목록에서 바로 가기**: 1~4를 건너뛰고 카드의 링크 버튼을 눌러 곧바로 포인핸드 페이지를 연다.

**변형 — 원문 공고 확인**: 5 대신 작은 「원문 공고」 링크를 눌러 국가동물보호정보시스템 페이지를 연다.

**변형 — 몸무게가 의심스러움**: 3에서 「15kg (원래 값: 15(Kg))」처럼 고양이로는 드문 값이 보인다. 프로그램은 값을 바꾸지 않는다. 사용자가 원래 값과 사진을 보고 판단하거나 포인핸드·보호소에 확인한다.

**변형 — 사진을 못 불러옴**: 2에서 사진 자리에 빈 그림이 뜨고 나머지 정보는 그대로 보인다.

**성공 조건**: 카드를 누른 뒤 두 번 이내의 클릭으로 그 아이의 포인핸드 페이지가 브라우저에 열린다. 열린 페이지가 프로그램에서 본 아이와 같은 공고번호다.
**연관 요구사항**: [[PAW-PRD-001#R2]] · [[PAW-PRD-001#R7]] · [[PAW-PRD-001#R8]] · [[PAW-PRD-001#R9]]

#### S4 며칠 뒤 다시 켜서 확인하기

**주체**: P1
**상황**: 며칠 전에 프로그램을 설치해 봤다. 새로 들어온 큰 아이가 있는지 궁금하다.

1. 시작 메뉴에서 프로그램을 연다
2. 켜자마자 다시 받아온다. 며칠 전 결과가 아니라 지금 포인핸드 기준 목록이 보인다
3. 마지막으로 받은 시각이 방금으로 바뀐 것을 확인한다
4. 프로그램을 켜 둔 채 한참 있다가 「새로고침」을 눌러 다시 받는다

**변형 — 받는 중에 새로고침**: 2나 4에서 받는 동안에는 「새로고침」 버튼이 눌리지 않는다. 같은 요청이 겹쳐 나가지 않는다.

**변형 — 포인핸드가 응답하지 않음**: 2나 4에서 실패하면 S1의 인터넷 끊김 변형과 같이 이유와 「다시 시도」가 뜬다.

**성공 조건**: 켤 때마다 최신 목록을 10초 안에 본다. 프로그램이 스스로 반복해서 포인핸드에 요청하지 않는다.
**연관 요구사항**: [[PAW-PRD-001#R1]] · [[PAW-PRD-001#R10]] · [[PAW-PRD-001#N1]] · [[PAW-PRD-001#N2]]

#### S5 새 버전을 만들어 나눠 주기

**주체**: P2
**상황**: 화면을 조금 고쳤다. 이미 설치한 지인들에게 새 버전을 주고 싶다.

1. 고친 코드를 저장소에 올리고 버전 태그(예: `v0.2.0`)를 올린다
2. GitHub Actions가 Windows에서 `setup.exe`를 만든다
3. 만들어진 `setup.exe`가 GitHub Releases에 새 버전으로 올라간다
4. Releases 링크를 지인들에게 보낸다
5. 지인은 S1과 같은 방법으로 새 `setup.exe`를 실행한다. 앱을 지우지 않아도 기존 설치 위에 덮어서 설치된다. 요구: [[PAW-PRD-001#R11]]

**변형 — 빌드 실패**: 2에서 실패하면 Releases에 아무것도 올라가지 않는다. P2가 Actions 기록에서 실패 이유를 보고 고친 뒤 태그를 다시 올린다.

**성공 조건**: P2가 태그를 올린 것 말고는 손으로 빌드하지 않아도 새 설치 파일이 Releases에 생긴다.
**연관 요구사항**: [[PAW-PRD-001#R11]] · [[PAW-PRD-001#R12]]
